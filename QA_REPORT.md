## Что ещё нужно настроить

### TomTom

В `apps/api/.env` добавить:

```dotenv
TOMTOM_API_KEY="ваш ключ"
TOMTOM_FREE_TIER_CONFIRMED="true"
TOMTOM_ROUTING_MONTHLY_CAP="18000"
TOMTOM_MANUAL_RESERVE_RATIO="0.2"
```

Затем перезапустить API и выполнить один ручной запрос трафика. Без ключа приложение продолжает работать через OSRM с видимой пометкой об отсутствии актуальных пробок и проверки LKW-ограничений.

### OpenAI для Excel

В `apps/api/.env` добавить `OPENAI_API_KEY` и при необходимости `OPENAI_IMPORT_MODEL`, затем перезапустить API. Стандартные таблицы обрабатываются локально; OpenAI используется только если локальный парсер не распознал ни одного заказа. Оригинальный файл не сохраняется, результат всегда остаётся предпросмотром.

## Ограничения

- Без GPS нельзя доказать фактическое положение или соблюдение режима; это диспетчерская расчётная модель по машине.
- Реальный TomTom и реальный OpenAI не проверялись без пользовательских ключей.
- До внешнего/многопользовательского развёртывания нужны авторизация, роли, rate limiting и обслуживаемая картографическая инфраструктура.
