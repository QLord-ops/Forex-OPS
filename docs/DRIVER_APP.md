# Приложение водителя OPS Fahrer

Для служебных телефонов Samsung Galaxy A26 (Android). Ставится из браузера, без Google Play.

## Диспетчер: выдать код

1. OPS Disponent → карточка машины → вкладка «Тур» → блок «Приложение водителя» (или страница машины).
2. Выбрать срок: 15 ч (смена), 24 ч, 3 дня или 7 дней (рейс) → «Выдать код».
3. Код из 6 цифр показывается **один раз**: продиктовать или отправить водителю вместе с номером машины. В базе хранится только его отпечаток.
4. Там же видно: водитель ещё не входил / в приложении / код заблокирован (5 неверных попыток подряд — выдать новый).
5. «Новый код» и «Завершить смену» сразу выкидывают телефон из приложения.

## Водитель: установить один раз

1. Открыть в **Chrome** адрес приложения (выдаёт админ, например `https://ops-fahrer.vercel.app`).
2. Внизу появится «Установить на телефон» → «Установить». Если нет: меню Chrome «⋮» → «Установить приложение» / «Добавить на главный экран».
3. На экране появится иконка OPS Fahrer — дальше открывать только её.

Через систему управления телефонами (Samsung Knox Manage, Intune и т. п.) админ может разослать ссылку как веб-приложение на все телефоны сразу.

## Водитель: работа

- Вход: номер машины (`GÖ-FX 214` или `214`) и код смены от диспетчера.
- «Прибыл» на точке, после выгрузки/загрузки — «ENTLADEN/BELADEN выполнено» → «Подтвердить». Отметка записывается сразу, диспетчер получает уведомление.
- Ошибся — «Отменить» в течение 5 минут, потом только через диспетчера.
- «Проблема на точке» — сообщение диспетчеру (долго жду, груз не готов, повреждение, не тот адрес).
- **Без сети** приложение открывается с последним туром. Отметки сохраняются на телефоне со временем нажатия и уходят сами, когда сеть появится (оранжевая плашка «ждут связи»). Отметку старше 12 часов сервер не примет — тогда сообщить диспетчеру.

Позиция машины берётся только из Webfleet, телефон её не передаёт. Имя и телефон водителя приложение не хранит.
